# Partes Application

A local desktop application for managing reports and statistics.

## Tech Stack
-   **Frontend**: React, Vite, Tailwind CSS, Recharts, React Big Calendar.
-   **Backend**: Node.js, Express, MongoDB (Mongoose).
-   **Wrapper**: Electron.

## Quick Start
1.  Ensure MongoDB is running.
2.  Run `npm start`.

## Features
-   Calendar View
-   Dashboard with PDF Export
-   Local Data Persistence (MongoDB)
